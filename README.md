# Shruti Singhal – Portfolio

Same layout as my Salesforce (LWC) portfolio, rebuilt as a plain website so it runs free on GitHub Pages.

## Update content
Edit **`data.js`**:
- **Projects:** copy a `{ ... }` block in `projects`. Put the live link in `live`, GitHub link in `code`. QR codes are made automatically. Optional screenshot: add the image file and set `image: "my-screenshot.png"`.
- **Photo:** save your photo as **`photo.jpg`** in this folder.
- **Resume:** replace `Shruti_Singhal_Resume.pdf` (same file name).
- **Languages / superbadges:** fill the lists under `other`.

## Publish
1. New public GitHub repository named **`Shrutisinghal2.github.io`**.
2. Push these files, then Settings → Pages → Branch `main`, `/ (root)` → Save.
3. Live at **https://shrutisinghal2.github.io/**
